# Минимальная задача кодовому агенту: выпуск экскурсии на ювелирное производство

Модель: `Sol high`

Репозиторий: `onedayonemasterpiece/kdg80`

Рабочая ветка: `feat/amber-combine-jewelry-excursion`

Не создавай новую ветку и не начинай реализацию заново. Продолжай именно в указанной ветке. Перед изменениями прочитай `AGENTS.md` и `docs/amber-combine-jewelry-excursion-2026-08-11.md`.

Основная реализация уже подготовлена:

- migration нового special event;
- полная публичная страница с работающей механикой заявки, загрузкой нескольких фото, precheck и multipart fallback;
- SEO, Open Graph и Schema.org;
- карточка первой в `/special/`;
- прошедшая экскурсия на судостроительный завод больше не показана как новый активный спецпроект;
- число победителей не выводится в пользовательском контенте нового события.

Твоя оставшаяся задача — только интеграция, проверка и выпуск.

## 1. Добавить два готовых изображения

Локальные входные файлы приложены к задаче:

- `amber-combine-jewelry-production.webp`
- `amber-combine-jewelry-production-og.webp`

Скопируй без повторной перекодировки:

- в `site/public/generated/special/amber-combine-jewelry-production.webp`
- в `site/public/generated/special/amber-combine-jewelry-production-og.webp`

Проверь фактические размеры: основной файл `1200×900`, OG-файл `1200×630`.

## 2. Точечно заменить hero главной страницы

Файл: `site/src/pages/index.astro`.

Не рефактори hero и не меняй другие истории. Замени только активный прошедший `yantarHeroVariant` судостроительного завода на новое событие.

Используй:

- image: `/generated/special/amber-combine-jewelry-production.webp`
- event slug: `amber-combine-jewelry-excursion`
- token: `amber-combine-jewelry-20260811`
- eventHref: `/special/amber-combine-jewelry-excursion/`
- prompt и label: `Спецмероприятие по итогам фестиваля`
- title: `Как янтарь становится украшением`
- body: `Редкий визит на действующее ювелирное производство Калининградского янтарного комбината Ростеха — для активных участников фестиваля «80 историй о главном». 11 августа · 11:00.`
- CTA: `Подать заявку`
- priority: не ниже прежнего `995`

Сохрани существующую проверку `applicationAvailable` через `specialRegistration`. Не удаляй архивную страницу `/special/yantar-excursion/`.

## 3. Добавить короткий канонический раздел требований

В конец `Исходные данные/Спецмероприятия/specialregistration.md` добавь раздел `Спецмероприятие «Экскурсия на ювелирное производство Калининградского янтарного комбината»`.

Зафиксируй без перефразирования механики:

- дата `11 августа 2026, 11:00`;
- площадка `Калининградский янтарный комбинат, посёлок Янтарный`;
- визит идёт в действующее ювелирное производство, не в музей;
- минимум `5` штампов;
- внутренняя квота `6` победителей;
- публично количество победителей не указывается;
- розыгрыш автоматически за сутки;
- точка сбора и требования пропускного режима сообщаются победителям персонально;
- все новые пункты получают статус `Не подтверждено пользователем`.

Не пересобирай и не переписывай существующий документ.

## 4. Проверить и выпустить

Выполни:

```bash
cd registration
npm ci
npm run check
npm run test:special-draws
npm run test:special-social

cd ../site
npm ci
npm run build
```

Проведи Playwright visual gate:

- новая страница: desktop `1440×1000`, mobile `390×844`;
- `/special/`: desktop и mobile;
- главная: новый hero на desktop и mobile.

Проверь:

- изображения грузятся и не искажены;
- мастер, инструмент и янтарь видны в hero-кропе;
- нет горизонтального скролла;
- дата `11 августа 11:00` загружается из API;
- CTA формы доступен;
- в пользовательском тексте страницы, карточки, hero, meta и Schema.org нет числа победителей;
- старые special pages собираются без регрессий.

После зелёных проверок:

1. закоммить только связанные файлы в эту же ветку;
2. push ветку;
3. выпусти сначала registration backend, затем сайт;
4. не создавай production-заявку без необходимости; при технической необходимости ФИО должно начинаться с `ТЕСТ`;
5. проверь production health, публичный event endpoint, страницу, `/special/` и hero;
6. обнови существующий draft PR или создай его из `feat/amber-combine-jewelry-excursion` в `main`.

В отчёте дай commit SHA, результаты команд, ссылки/пути скриншотов, Fly release backend, URL новой страницы и отдельное подтверждение, что число победителей не отображается на публичных поверхностях.
